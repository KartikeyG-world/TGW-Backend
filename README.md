# TGW Backend

A curated collection of backend development projects built while learning and practicing modern **Node.js** development. This repository showcases hands-on implementation of authentication, RESTful APIs, database integration, file uploads, and full-stack application architecture using industry-standard technologies.

The primary objective of this repository is to strengthen backend development fundamentals through practical projects while following scalable project structures and clean coding practices.

---

# Repository Overview

This repository currently contains the following projects:

## 1. Authentication API

A RESTful authentication system demonstrating secure user management and authentication workflows.

### Key Features

* User Registration
* User Login
* Password Encryption
* JWT Authentication
* MongoDB Integration
* Express Routing
* MVC Project Structure
* Environment Variable Configuration

---

## 2. Post Creator Application

A full-stack application consisting of a React frontend and a Node.js backend that allows users to create and manage posts with image uploads.

### Key Features

* Create Posts
* Image Upload Support
* MongoDB Database
* REST APIs
* React Frontend
* Express Backend
* Mongoose ODM
* Image Storage Integration
* Modular Backend Architecture

# Getting Started

## Clone the Repository

```bash
git clone https://github.com/KartikeyG-world/TGW-Backend.git
```

## Navigate to the Repository

```bash
cd TGW-Backend
```

Each project contains its own dependencies and can be installed independently.

Example:

```bash
cd Authentication
npm install
npm start
```

or

```bash
cd Post_Creater_Application/backend
npm install
npm run dev
```

For the frontend:

```bash
cd Post_Creater_Application/frontend/PostCreator
npm install
npm run dev
```
